# Portfolio Readiness

- [ ] Business problem and intended decision are clear
- [ ] Stakeholders and objectives are documented
- [ ] Data sources and permitted access are documented
- [ ] Data dictionary and cleaning decisions are documented
- [ ] Analysis can be reproduced
- [ ] Results were validated with relevant checks
- [ ] Charts answer the stated business questions
- [ ] Methods, assumptions, and limitations are explained
- [ ] Recommendations follow from the evidence
- [ ] README and reproduction instructions are complete
- [ ] Screenshots or working links are available
- [ ] Published content contains no credentials or restricted material
- [ ] Resume bullets describe actual completed work
- [ ] A 3–5 minute project explanation is prepared
